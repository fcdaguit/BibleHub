# User manual

**Sermons tab**: create (+), search, use each item's menu for export, move to folder, duplicate and archive. Import TXT/DOCX/PDF with the upload icon in the top bar.

**Editor markup**
```
# Heading        ## Subheading
- bullet         1. numbered       > note/quote
**bold**  _italic_  ==highlight==  {red}coloured text{/}
```
Scripture references (e.g. John 3:16) are underlined as you type; tap one to open a floating verse popup (copy, insert into outline, open chapter) without leaving the sermon. Detected references also appear as chips above the keyboard.

**Bible tab**: choose book/chapter, switch versions, compare versions side by side, bookmark verses.

**Search tab**: type a reference, keyword, phrase, topic or question ("first miracle of Jesus"). Results show verses, related passages and cross-references.

**Assistant tab**: outline from a topic (12 sections), sermon from a passage (topical, expository, textual, etc.), or scripture recommendations by topic. "Save as outline" opens the draft in the editor. Always review the output.

**Notes tab**: notes with tags/topic/verse, and bookmarks (star favourites).

**Settings**: theme (system/light/dark), dynamic colour, language (English, Tagalog, Cebuano), default version, AI engine (template, or on-device model file), auto/manual backup, export/restore backup.
