# Installation

1. Build the debug APK (docs/BUILD.md) or run from Android Studio on a device/emulator (Android 8.0+).
2. To sideload: copy `app-debug.apk` to the phone, allow "Install unknown apps" for your file manager, open the file.
3. First launch seeds a 62-verse KJV sample and three sample sermons.
4. Settings > Manage Bible versions > Import file to add a full Bible (see BIBLE_IMPORT.md).
